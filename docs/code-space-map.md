## 3. Verdicts

| Verdict | Meaning |
|---|---|
| USABLE-DATA | every check is PASS; free bytes may hold tables |
| USABLE-CODE | as USABLE-DATA, and a camera-tested spec already runs code in this area (a relative jump from outside into its bytes; `docs/camera-log.md`) |
| USED | every check is PASS, no free byte left (current specs) |
| NEEDS-DECISION | a check is UNKNOWN, or `pointers`, `operands` or `predecessor` did not pass; a person must decide or add evidence |
| REJECT | `loaded`, `content` or `written` failed |

Checks: **loaded** (inside a boot copy), **content** (all 0xFF, or listed as reclaimed), **pointers** (no 4-byte value at any byte offset of block 0 equals an address in the area, in any of the 4 aliases), **operands** (no branch target or absolute operand that objdump prints inside a function), **written** (section 2), **predecessor** (what ends before the area, and whether the reader of the object before it is known to stop).

Windows in blocks 1-3 and the tail of the update file are counted per area in `docs/code-space-map.tsv` (column `pointers_evidence`) but do not change a verdict: those blocks are resources, the tool has no decode for them, and it cannot classify a window there.

Pointer windows that are explained and do not count as hits: `code-nonoperand` (not 4-aligned, inside a function, and not the operand of the decoded instruction: depends on the decode), `straddle` (not 4-aligned in data, and the window runs into a 4-aligned word that is itself a block-0 address), `double` (the 8 bytes are a short decimal constant), `double-table` (the window lies in three consecutive 8-byte cells that are all doubles: exponent between 2^-47 and 2^49, 5 to 27 bits set in the low word, low word not a block-0 address), `from-listed` (the site is inside a listed reclaimed area), `end-constant` (the exclusive end of a known copy source, at its site), `waived` (hand file). Everything else is a hit.
