**Install**

1. Download under Assets: the `.dmg` for a Mac, the zip for Windows and Linux.
2. Start the installer:
   - Mac: open the `.dmg` and double-click **EPM2Mod**. To keep it, drag it to Applications first. When macOS asks, select **Open**.
   - Windows: unzip, then double-click **Start (Windows).bat**. If Windows protects your PC: **More info** → **Run anyway**.
   - Linux: unzip, then run `./start.sh`.
3. A page opens in your browser. Follow it: it writes to your SD card (or gives a zip) and ends with the steps for the camera.

If the IS icon blinks when you turn the camera on, its image stabilizer is broken. In the installer, select EPM2Mod, open **Other options**, and select **My camera's image stabilizer is broken**.

This firmware is unofficial and only for the Olympus PEN E-PM2.
