## Where the map is weakest (this batch)

1. **Transition actions and helpers below the state level.** The rule-built rows give callee lists for helpers (F042, F049, F055). The reader has to rebuild the role from the callees: a dtor without a vtable store, the four trimming move steps, the history re-entry on 11799.
2. **Big state entries with a payload switch.** F050's row lists the first events it finds and stops. The 8-way switch on +576 and the 7091/12067 exit are not in the map. 15c §4.5 lists where CustomPrint requests go but not state 135.
3. **Event meaning in the 13781–13905 (CustomPrint/EasyPrint) and 11799/11843 ranges.** The ids and owners are known; names and payloads are not.
4. **GUI check tables.** 16b gives the position and the log string of each entry of 0x7EED0BBC but not that the table is a judge chain for direct mode start (1 = OK, first 0 stops), or what key code 2110 is.
5. **Guards are dropped from handler rows.** F051 and F054 transitions depend on 0x7EA7D270 / 0x7EA7D28D ("all started / all stopped"). The rows show them as unconditional.
