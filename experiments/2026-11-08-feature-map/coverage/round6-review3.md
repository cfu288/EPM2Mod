## CONTRADICTED items

No function verdict is CONTRADICTED. Some map rows near these functions are false or incomplete:

- **16a 0x7E966CCE "HIGHLEVEL_MAIN / HLS startup method"** is wrong. It is a generic pointer-collection remove(item): count at +4, array at +12; it finds a1, overwrites it with the last element and decrements the count (V, 0x7E966CCE–0x7E966CFC). 15c already uses it as "removed through 0x7E966CCE" (with 0x7E966C01 = add). It has 20 callers across the app layer, so the position-based role is false.
- **16b 0x7ED1F53A "merged 1 unreachable stub"** undercounts: 7 vtable methods are merged (see F057).
- **16b 0x7ECEF6A6 (3 B, "vt slot 0")** is the first instruction of the data-model dtor. Its body continues in 0x7ECEF6A9 (a fwmap split).
- **15c CmpPCw role "(I: calendar week?)"** does not fit the class's `cw_*` OSD-canvas strings. Section 06 already reads it as a CW canvas.

## Weakest areas

1. **GUI draw-object family and renderers (16b).** There is no slot dictionary, and three of six GUI functions get only context rows. Type 0x200C (F058/F059) is an animated, keyframed blur effect: slot 4 = set keyframe and step, slot 15 = draw an N-pass 4-neighbour blur through the shadow buffer 0x605F63CE. None of this is in the map. The WinMain slot 197 factory 0x7ED1AFF9 (type ids 0x2000–0x2012, jump table 0x7EF0FF30) is indexed only as "vt slot 197".
2. **CA_MAIN behaviour.** The boot-warning chooser 0x7ECD6031 (`error Card/Date/Lens/AVCHD/none`), the warning code at 0x605EFDCC, the date-setup and isMirrorSetup gating, and info id 99 (prm 0x8A81, unnamed) are not described. 16b gives "helper of …" rows here.
3. **Anonymous 16b classes for objects the map already knows.** F056 is the ctor of the 07 §5 data-model singleton (getInstance 0x7ECEF5DC, vt 0x7EEF54C8), but the index calls it `class@0x7EEF54C8`. The map does not join the two.
4. **16a state numbers are missing when a handler is reached through a forwarder or a region dispatcher** (F042 = 65, F043 = 27, F048 = 19, F051 = 29). Transient entries that begin with pushNullConfig get no state number (0x7EAF21C5 = PictBridge 27 `backgroundctrl_draw`). Reading the jump tables gives all of these directly.
5. **Per-class extensions of the play choice.** 15c §4.2 lists the base +572 command table. CmpERaw's state-15 choice adds 284, 341 and 402–409 (end_custom_edit, end_current_mode_edit, …), which no section records.
6. **Side effects in shape-labelled rows.** "transition-step" and "handler" rows leave out the observer notify (F054: +148 list) and history writes (F052: +328). An index user would miss the notify that the boot chart depends on.
7. **modules.tsv** covers 2 of 20. All the GUI functions are in a single 0x7EBA56EC–0x7EDE2AAB gap.
