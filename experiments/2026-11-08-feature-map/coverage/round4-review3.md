## Contradictions

No function verdict is CONTRADICTED.

**C1 (secondary, V): `15c-class-index.tsv` row `Cab_CameraBase facade`, end 0x7EB8E2B3, is wrong.**
- The regions table and 15c §1 end the Com_ framework at 0x7EB8C265 and start `Dev*` part 1 there.
- 15c §5 and other class-index rows give classes in the Cab range:
  - Dev picture/display size 0x7EB8C5E1–0x7EB8C8D1;
  - display device 0x7EB8C8D2–0x7EB8D849;
  - handle holders 0x7EB8D84A–0x7EB8E2B3.
- F053 0x7EB8CAAF is slot 10 of the display-device vtable 0x7EC8DEDC (stored by ctor 0x7EB8C8D2) and of the derived vtable 0x7EC8E57C. It is not Cab_CameraBase code.
- So a range lookup gives two owners for every address in 0x7EB8C265–0x7EB8E2B3.
- Fix: the Cab facade ends no later than 0x7EB8C264.

Other errors and gaps (not contradictions):
- **Missing event name.** 16143 has no name in 13c-event-ids.tsv or 15c-event-id-fixes.tsv. Handler 0x7EA7070D tests 16143 and then logs `%s(%d):RECEIVE EVENT evTraCmpSts_RecViewAbort`, so 16143 = `evTraCmpSts_RecViewAbort` (V). On its other branch the same handler takes 7009 (`evTraCom_OperationSuccess`).
- **Tool split error.** functions.tsv merges the getter 0x7EB920D2 (vtable word 0x7EC8EBBC) into F054.

## Weakest areas

1. **The GUI renderer layer 0x7ED30000–0x7ED37DA9.** 14e gives roles only up to the slanted-fill routines. The mask and alpha blits (F056 and its sibling 0x7ED36A6F) have no rows. Neither has the small draw-object class family 0x7ED1F4F4… (vtables 0x7EF10EA4, 0x7EF10EF0, 0x7EF10F3C, 0x7EF10F88, each 19 slots) that calls them, or the image table 0x7EFB13BC.
2. **What the panels show.** The 15a panel rows give the structure (range, type, vtable, resource, who shows the panel), but no role for any child or field.
   - Panels 20 (pages 423–433) and 42 have no role. The map says so for pages 423–430.
   - Panel 10 (the live-view screen) has 155 children, and no child id is named.
   - The blink-list mechanism 0x7EDC6BDB/0x7EDC6C60 (timer 250) is not described.
3. **Per-class work states of the play and edit components.** 15c §4.2 names the base command states. The extra states of each class are named only for LightBox. Unnamed examples:
   - `start_expand_animation_start` (state 51, in 11 classes, helper 0x7EB0ED3C → Set/Start_Effect);
   - CmpPMov `playmovie_start_movie_service` (53);
   - the movie-start entry `Cap_PlayMovie::idle_play_start` → `Load_Play_Movie`.
4. **Event names that the code logs.** Some handlers log the event name right after the isTypeOf test (for example, 16143 = RecViewAbort), but the dictionary still leaves those ids without a name. The 16061–16164 `evTraCmpSts_*` block is the most affected.
5. **GUI event records outside 0x7EEDD–0x7EEDE.** The `{code, 1, 1, handler}` records continue at least to 0x7EEE03D0–0x7EEE055C, with code families 0x0106xxxx, 0x0300xxxx and 0x0900xxxx. The map has no table of codes, so a handler such as F055 cannot be connected to its trigger (for example, 0x01060008 = lens connect change, I).
6. **Dev wrapper lists.** Some methods are missing. The DevMed list omits `api_rec_Set_Filename_Custom` (F054). The info ids 147–154 (custom file-name characters, I) are not in 07-settings.tsv.
