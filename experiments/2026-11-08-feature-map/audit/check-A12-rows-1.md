## Notes on WRONG/MINOR rows and the likely rule

- **0x7E9CDE02 (WRONG):** the generic vcall rule `idx16.py:506` labels any `vt+48` vcall "schedule timeout". That holds only for the Com_ timer interface. Here vt+48 is a UTF-16 wcsncat in the 0x7E9678C8 singleton.
- **0x7EDDBCA2 (MINOR):** the class-row text was cut at a fixed length mid-address ("RAM 0x602BD").
- **0x7ED719EB (MINOR):** the small-code describer (`micro.py`, "code,shape,callee") turns a tail call into "returns result of X". No caller reads d0, and X has no defined result. It also leaves getChild(136) as a bare call.
- **0x7E507325 (MINOR):** curated text (14b §2) copied to all 6 scheap wrappers (0x7E5072ED…0x7E507379). It calls the a0 argument a pool and 0x7E436593 a lock. a0 is a function pointer, and the core is a dis_dsp/ena_dsp wrapper. The same false detail is in 6 rows plus the 0x7E507395 row.
- **0x7E5C8D48 (MINOR):** the D5 hand-read example path was written without the drive prefix that the caller 0x7E5AFB62 shows.
