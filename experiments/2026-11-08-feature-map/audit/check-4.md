## Notes on the non-CORRECT claims

**07-272 (MINOR).** The strings, `startVersionCheckMenuSubAppStateMisc` 0x7ECE0653 and 0x7EDFD86F are all correct. The first evidence address, 0x7EDA6D93, is a different function (SsMenuLv animation; 1059 bytes, ends 0x7EDA71B6, one string). The `F/W Version up start` log is in 0x7EDA9D03 at 0x7EDAA63F. The same wrong address is reused in section 07 §5 ("Warnings … in 0x7EDA6D93"). There, `[GUI Warning]` is actually in 0x7EDB0847 and `Warning_Viewer` is in 0x7EDC25D4. The firmware-update sentence is supported. Wizard item 43 posts CA event (11, 12), and the CA handler 0x7ECDCB10 turns info 12 into sub-app request 13 = CAM_MISC_FIRMUP. Info 11 becomes 12 = CAM_MISC_VERCHK_MENU. I did not tie item 43 to the "Firmware" label (top-table record 0x7EFFE29A has item_id 0), and I did not trace the GUI-event-11 → 0x7ECDCB10 dispatch.

**07-275 (UNCHECKABLE, part).** `CmpCst_Function` 0x7EAA8FF9 and both api_rec Pixelmaping strings are correct. "Custom Menu J" (Utility) matches the camera's documented menu. But no firmware table shows Pixel Mapping (string 207) under the Utility page (item 175 → page 185 → generic panel 0x7EDCBFAA/0x7EDCC154). The one u16 207 in the sub-item table (0x7EFEF94C) is an info id in the Sharpness row, not this label.

**08-17 (MINOR).** The ops are written as a range, 0x9119–0x9125, and that overstates the set. Five codes in that range (0x911A, 0x911B, 0x911D, 0x911E, 0x911F) are registered in no builder. The registered firmware-update ops are 0x9117, 0x9119, 0x911C, 0x9120, 0x9121, 0x9122, 0x9123, 0x9124 and 0x9125. The FirmwareCheck → queue 134 → FIRMUP_SRV link is verified.

**08-59 (MINOR).** The TEST_PACKET address is off by 9 bytes. The only code reference (0x7F09BE12) uses 0x7F0D7C58 with length 53, and 0x7F0D7C61 is where the AA run begins. Also, the stored last byte is 0xE7, while the USB 2.0 test packet ends in 0x7E. The claim's pattern summary ("7F BF DF…") does not cover the tail, but a reader who expects the exact spec pattern should know the last byte differs.
