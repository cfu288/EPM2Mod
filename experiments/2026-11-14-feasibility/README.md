# Feasibility study, 2026-11-14

Question: what can a firmware mod do on the E-PM2, and which limits are real?

Three research notes, each with sources and a label on every claim (verified, reported, inferred,
unknown):

- [hardware.md](hardware.md): processor, memory, sensor, shutter, video encoder, card interface, and
  the features of sister bodies that this body has the hardware for.
- [firmware.md](firmware.md): free code space and RAM, file reading from the card, the Picture Mode
  list, the image stages, features that have text or code but no menu entry, the menu toolkit, the
  emulator.
- [caduceus.md](caduceus.md): how the Caduceus mods for the OM-3 and the E-P7 did each feature, and
  what transfers to this body.

The summary and the working rules that follow from it are in
[docs/feasibility.md](../../docs/feasibility.md).

In the notes, `REPOS/` is a folder of third-party checkouts and `/tmp/scratch/` is a scratch folder.
Neither is in this repository.
